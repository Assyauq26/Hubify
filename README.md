# Hubify

Hubify is a project knowledge hub for organizing projects, notes, and useful links in one place.

## Phase 1

Phase 1 establishes the application foundation and core workspace features:

- Authentication
- Project CRUD
- Notes CRUD
- Rich-text notes editor
- Link Manager
- Responsive, mobile-first UI
- Supabase Auth/PostgreSQL/Storage integration

## Status

Phase 1 foundation is being implemented from the approved Hubify PRD.
